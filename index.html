Crazy Rummy network test

Use this PC on home broadband and one phone with Wi-Fi switched off. Nothing is installed and no card information is involved.

Pair the two devices

Both devices must show the same six-character code. On the phone, open this launcher, enter the code shown on the PC, and press Use this code.

1. Automatic-path test

  1. Confirm the phone shows the same code as this PC.
  2. On the phone, tap Open phone side on this device.
  3. On the PC, tap Open desktop side.
  4. Both screens should report Passed and name the selected path.

  1. Close the two direct-test pages.

  3. Open the phone relay side, then the desktop relay side.
