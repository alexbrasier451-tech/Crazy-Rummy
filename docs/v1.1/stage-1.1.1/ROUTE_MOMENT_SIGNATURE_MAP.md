# Stage 1.1.1 route and moment signature map

**Selected-direction basis:** Compartment Table  
**Decision state:** Owner-approved direction; initial implementation map

## Major routes

| Route | Distinctive visual idea | Truth/accessibility protection |
| --- | --- | --- |
| `/` | One station node resolves in a dark platform void, followed by the complete route mark. | Static complete mark for reduced motion; load/error copy remains text. |
| `/identity` | A personal seat ticket and punched marker establish local identity. | Visible label, validation, keyboard-safe action; marker is never colour-only. |
| `/lobby` | Threshold board plus offset public table tickets emerging from a corridor. | Only public discovery metadata; freshness and offline state remain explicit. |
| `/waiting-room` | Six seat plaques converge toward a departure line; ready marks advance it to `Depart`. | Ready labels remain text; host authority never auto-starts. |
| `/game` | Adaptive six-seat compartment perimeter, recessed shared table, foreground private hand. | Public/private boundary, semantic reading order, full card targets, honest network rail. |
| `/hand-result` | Accepted totals unlock as a station ticket on the thirteen-stop ledger. | Authoritative public result first; owner-private breakdown remains separated. |
| `/final-result` | The route reaches a terminus ticket; standings lead and history recedes. | One restrained flourish only after final authority; none for reduced motion. |
| `/rules` | A timetable annotation layer connects rule sections to the hand/wild route. | Ordinary headings, links, and reading order remain primary. |
| `/settings` | Device controls sit on a service-panel ticket with local/offline provenance. | Persistent labels, native controls, safe clear-data confirmation. |

## Named moments

| Moment | Signature | Reduced-motion / truth rule |
| --- | --- | --- |
| Arrival | One route node and threshold light establish the world. | Render final state immediately. |
| Table formation | Seat plaques occupy numbered positions as players are accepted. | Never show a seat before authority accepts it. |
| Ready/depart | Each accepted ready state punches one plaque; the route reaches `Depart`. | Text remains authoritative; no auto-start implication. |
| Wild rank | Rank plus `WILD` route seal appears in the fascia and on affected cards. | Text and patterned edge survive colour loss. |
| Shuffle/deal | Anonymous backs leave stock for seat markers; only the local hand turns face-up. | Immediate safe layout; never expose opponent faces. |
| Opening hand | The local foreground tray settles and announces its count. | Static tray and count. |
| Local turn | Local plaque and one table-lens boundary become the focal point. | `Current turn` text is always present. |
| Draw stock | After acknowledgement, the card moves from stock to the local tray and neighbours reflow. | Immediate accepted destination; pending remains at source. |
| Take discard | The named discard moves to the local tray after acknowledgement. | Same authority rule as stock draw. |
| Select/sort | Selected card lifts, gains a check, and keeps a labelled selection count. | Static edge/check; sorting never re-deals. |
| Meld | Accepted selected cards travel together to a labelled public siding. | Immediate accepted public group; `Set`/`Run` and wild meaning stay textual. |
| Invalid meld | Cards remain staged under a patterned signal edge with one repair instruction. | No punitive shake. |
| Replace wild | A two-lane exchange receipt maps natural card to slot and wild to local hand. | Both destinations update together only after acceptance. |
| Discard | Accepted card reaches discard, then and only then the current-turn boundary advances. | Immediate two-state update with status announcement. |
| Reconnect | A persistent signal rail and countdown overlays the last safe, subdued table. | No ambient/decorative motion; conflicting actions freeze. |
| Recovered | `Back online · table up to date` replaces the rail while safe focus/selection remains. | No replay or celebration. |
| Hand complete | The next route node activates once. | Static current/next labels. |
| Score reveal | Accepted totals unlock as a public station ledger. | No private hand details enter public presentation. |
| Next wild | The route notch advances and names the next rank. | Static named rank. |
| Kings hand | The final route segment receives a king seal after authoritative hand completion. | No early finale. |
| Final reveal | Terminus ticket and standings resolve, followed by one small foil response. | No flourish for reduced motion; standings remain first. |
